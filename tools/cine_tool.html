오의 연출 편집기

스킬 id 마다 연출(암전·줌·이펙트·번쩍임·히트스톱·배너)을 시간표로 짜고, 게임과 같은 엔진(cine.js)으로 미리 보고 → assets/cine/cine_manifest.js 로 내보낸다

① 연출

일격 시점 = 피해 숫자·피격 모션·번쩍임이 나오는 순간. 스킬 id 는 게임의 스킬 id(예: kenki, sacred, renkan, pierce, meteor, sanctuary, assassinate). 연출이 있는 스킬은 기본 동작·이펙트 대신 이 연출이 재생된다.

② 스텝

③ 내보내기

미선택 — ZIP·JSON 저장 가능
assets/cine/cine_manifest.js(window.CINE_MANIFEST) — 같은 스킬 id 는 덮어쓰고 나머지는 유지한다. 폴더를 고르면 기존 연출도 불러온다. 게임에 쓰려면 cine.js 와 이 파일이 index.html 에 로드돼 있어야 한다.
