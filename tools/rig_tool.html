자동 리깅 도구

그림 한 장 → 관절만 맞추면 걷기·대기·공격·피격·쓰러짐이 자동 생성 → 게임 시트(256 칸, 발바닥 80%)로 내보내기

1. 그림과 관절

순서 ① 기본 그림이 올라오면 색 점(관절)이 몸에 맞는지 봅니다. 어긋난 점은 끌어서 맞춥니다(주황=앞쪽 팔다리, 파랑=뒤쪽, 흰색=몸통·머리). ② 오른쪽에서 동작을 눌러 확인합니다. ③ 마음에 들면 "게임에 바로 적용"을 누릅니다.
캐릭터 키
점을 끌어서 몸에 맞추세요. 앞(가까운 쪽) 팔다리 = F, 뒤(먼 쪽) = B. 투명 배경 PNG, 오른쪽을 보는 옆모습이어야 합니다.
메시 간격가중치 거리 지수

2. 동작 미리보기와 내보내기

진폭100%속도화면 배경
적용하면 assets/side/anim/{키}/동작_0.png 가 바로 바뀌고, 이전 파일은 assets/side/anim/_backup/ 에 시각이 붙어 보관됩니다. 적용 후 게임(side.html)을 새로고침하면 반영됩니다(공격 타격 프레임도 자동 기록).
