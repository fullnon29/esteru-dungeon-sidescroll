PNG / WebP / JPG 여러 장 가능. AI가 만든 격자 시트, 구입한 시트 모두 가능.
PixelLab 등 프레임별 PNG(경로에 동작·방향·프레임 번호가 있는 것)나 ZIP. 방향(south, south-east…)과 동작 폴더를 자동 인식해 동작마다 시트 하나로 조립한다. 도트는 "원본 배치 그대로" + 프로필 변환 방식 "최근접"을 권장.
합치기: 몸·무기·갑옷처럼 같은 격자의 레이어 시트를 겹쳐 조합 시트를 만든다. 이름 예: knight@sword-plate
