이펙트 생성기

레이어를 쌓아 참격·충격·마법 이펙트를 만들고 → 도트풍 PNG 스트립 + 레시피(JSON)로 내보낸다. 코드로 그리므로 토큰 없이 직접 조절

① 프리셋 누르면 레이어가 채워진다

② 기본 설정

타격 프레임·히트스톱·흔들림·번쩍임·위치 오프셋·크기 배율은 이미지에는 안 들어가고 레시피(JSON)와 매니페스트에 기록된다 — 게임이 이 값으로 타격감을 연출하도록 연결할 때 쓴다. 오른쪽 "타겟 미리보기"로 느낌을 확인.

③ 레이어

미리보기

프레임 전체

타겟 미리보기 타격감 확인 — 맞는 쪽에 이펙트를 겹쳐 보여 준다

이펙트 위치는 ②의 오프셋(게임 px)을 그대로 쓴다 — 타겟의 발(점선 십자)이 기준

④ 내보내기

미선택 — ZIP 저장 가능
내보내기: {name}.png(가로 스트립, 프레임×칸) + {name}.recipe.json(다시 편집용) + fx_manifest.js(window.FX_MANIFEST, 같은 이름은 덮어쓰고 나머지는 유지). 폴더 쓰기는 크롬/엣지 전용.
