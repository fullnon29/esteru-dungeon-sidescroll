# 디자인 에셋 규격

에셋을 이 폴더(`assets/`)에 넣고 `assets/manifest.js`에 경로를 적으면 게임이 자동으로 사용합니다.
비워 두거나 파일이 없으면 기존 이모지/도형 표현으로 대체되므로 **일부만 먼저 넣어도 됩니다.**
(게임 안 `⚙ 설정 → 에셋 상태`에서 로딩 결과를 확인할 수 있습니다.)

## 공통
- 형식: PNG(투명 배경 권장), WebP 가능
- 해상도: 표시 크기의 2배 권장 (고해상도 화면 대응)
- 원작(컴파일) 에셋은 사용하지 않는 것을 권장합니다 (권리 문제 방지)

## 애니메이션 (선택)
- 용병은 정지 이미지 대신 가로 스트립 애니메이션을 쓸 수 있다. `manifest.js` 의 `anims.<용병 이름 또는 직업>` = `{ size, foot, fps:{동작}, path:'assets/anim/이름/{act}_{dir}.png' }`. 방향 `{dir}` 0~7(시계 방향: 0=E 1=SE 2=정면 3=SW 4=W 5=NW 6=뒷모습 7=NE)을 모두 갖춘다. 이동 중이면 가는 쪽, 공격·시전이면 대상 쪽을 바라본다.
- 동작: `idle`(대기) `walk`(이동) `atk`(기본 공격) `heavy`(강타) `sweep`(회전·범위 근접) `combo`(연타) `shoot`(원거리) `guard`(방어) `taunt`(도발) `cast`(마법) `hurt`(피격) `dodge`(회피) `die`(사망). 없는 동작은 아래 후보 순서로 대체된다(`idle`·`hurt` 는 있어야 자연스럽다). 스킬→동작: 강타 `heavy`→`atk`, 회전베기 `sweep`→`atk`, 연속 찌르기 `combo`→`atk`, 일제사격 `shoot`→`atk`, 방어태세 `guard`→`taunt`→`cast`, 도발 `taunt`→`guard`→`cast`, 마법·치유 `cast`→`atk`. 방어태세 중 맞으면 `guard`, 아니면 `hurt`, 빗나가면 `dodge`. 매니페스트 `hit: {동작: 타격 프레임}` 으로 피해 숫자·피격 모션이 그 프레임에 맞춰 나온다(없으면 40%). 스트립은 프레임 15장을 가로로 이어 붙인 PNG(프레임 128×128, 그림자 없음). `foot` 은 칸 안 발 위치(y). 선언이 없거나 못 불러오면 정지 이미지/이모지로 대체된다.
- 전투판(캠프 포함)·주점·미로 행렬에서 재생된다. 쓰러진 대원은 `die` 를 재생한 뒤 사라진다.
- **변환 도구(권장): `tools/anim_tool.html`** — 서버를 켠 뒤 `http://localhost:8123/tools/anim_tool.html` 을 크롬/엣지로 연다. ①원본 폴더(캐릭터 여러 개가 든 상위 폴더도 가능) ②게임의 `assets` 폴더를 고르고, 방향 확인 칸에서 방향별 행을 맞추면(프로필로 저장되어 다음 캐릭터에도 적용) 선택한 캐릭터를 한꺼번에 내보낸다. 결과는 `assets/anim/<이름>/` PNG 와 `assets/anim/anims.js`(manifest 항목, 자동 생성·병합)이며 `index.html` 이 `anims.js` 를 불러온다. 이름은 직업(`knight`)·용병 이름·몬스터 id(`goblin`)·보스(`boss10`)이고, 동작별 프레임 수는 `n` 으로 기록된다. 몬스터·보스도 같은 방식으로 애니메이션이 적용된다.
- 도구 없이 쓰려면 SmallScaleInt 계열 시트(1920×1024, 15열×8행)를 `powershell -File tools\extract_anim.ps1 -Src <시트 폴더> -Name <이름> -Dirs 0,1,2,3,4,5,6,7 -Out <assets\anim\이름 절대경로>` 로 변환한다(방향 = 시트 행 번호, 출력의 `foot` 값을 manifest 에 적는다).
- 현재 기사(knight)만 적용되어 있다. 라이선스상 원본 시트·재배포는 금지이므로 저장소를 공개할 때는 `assets/anim` 을 빼거나 라이선스를 다시 확인할 것.

## 범용 에셋 도구 (AI 격자 시트 → 게임용 에셋)
- `tools/asset_tool.html` — 서버를 켠 뒤 `http://localhost:8123/tools/asset_tool.html`(크롬/엣지). **다른 게임에도 쓸 수 있게 게임별 규격을 "프로필"로 분리**했다. 이 파일 하나만 복사해 가도 동작한다(의존성 없음).
- 입력: 2×2, 4×4, … 15×8 등 임의 격자의 시트 이미지(AI 생성물·구입 시트). 격자 자동 감지, 단색 배경(크로마키)/흰 배경/이미 투명한 이미지 모두 가능. 처리: 배경 제거 → 가장자리 잔티·색 번짐 정리 → 부스러기 제거 → 발 기준 정렬 → 같은 캐릭터는 모든 동작에 같은 배율 → 크기 변환(부드럽게/최근접/도트화) → 팔레트 제한(선택).
- 배경 제거 옵션: 크로마키(자홍·녹색·파랑 등)는 "색조로도 지움"을 켜면 배경색이 번진 어두운 그림자까지 지워지고, 칸 가장자리에 걸린 작은 조각(옆 칸에서 넘어온 그림)은 자동으로 지운다. 격자 자동 감지는 경계 부근의 작은 부스러기를 허용한다. 테스트용 합성 시트 생성기: `tools/_test/make_goblin.py <출력.png>`.
- **프레임 가져오기**(PixelLab 등 프레임별 PNG/ZIP): ②의 "프레임·ZIP 가져오기"/"폴더 가져오기". 경로에서 방향(south, south-east, east… 또는 down/left/up/right, 약자 e/se 등)·동작 폴더(walking-8-frames→walk, breathing-idle→idle 등 프로필 동작으로 자동 대응)·프레임 번호를 읽어 동작마다 시트 하나로 조립한다. 정지 `rotations` 이미지는 대기 동작이 없을 때만 idle 로 쓴다. 이미 규격 크기인 도트 원본은 "원본 배치 그대로"(배율 1, 칸 안 위치 유지, 발 위치는 원본에서 읽어 매니페스트에 기록) + 프로필 크기 변환 "최근접"을 쓴다(테스트: 8방향 픽셀 완전 일치). 도트 원본을 128 칸에 줄여 넣으면 품질이 크게 떨어지므로 생성 단계에서 캔버스를 칸 크기(128)로 만드는 것이 좋다.
- 애니메이션: 행=방향, 열=프레임. 행을 방향에 연결하고(4행 시트면 정면·좌·우·뒷모습 등), 없는 방향은 좌우반전 짝이나 가까운 방향으로 채운다. 정지 에셋: 칸마다 이름을 적으면 그 칸만 내보낸다.
- 프로필 `에스테르의 미궁`은 이 문서의 규격(128px 칸, 8방향, 발 y≈102, `assets/anim/<이름>/{act}_{dir}.png`, 정지 에셋 그룹별 크기)을 그대로 내보내고, 프로젝트 폴더를 고르면 `assets/anim/anims.js`(기존 항목과 합침)와 `assets/gen_manifest.js`(정지 에셋 경로, `index.html` 이 불러옴)를 자동 갱신한다. 다른 게임은 프로필을 복제해 칸 크기·방향 수·동작·경로 규칙·매니페스트(범용 JSON)를 바꾸면 된다. ZIP 저장도 가능.
- 시트에 맞는 **AI 프롬프트 생성기**가 있다(격자·행별 방향·동작·배경색·화풍 반영).
- 후처리(시트별): **외곽선**(단색/발광/그라데이션, 도트화일 때 두께 = 도트 1개), **그림자**(스프라이트에 합침 / 별도 시트 `이름_shadow`), **프레임 수 줄이기**(fps·타격 프레임이 재생 시간 유지되게 비례 조정되어 매니페스트에 기록), **정지(첫 프레임만)**.
- **색 변종**: 같은 시트의 색상·채도·밝기를 바꿔 `이름+접미사`로 함께 내보낸다(몬스터 변종·정예·황금 몹용). 범위 지정을 켜면 해당 색상 범위(예: 붉은 갑옷)만 바뀐다. 랜덤 변종 생성 가능.
- **합치기**: ②에서 같은 격자의 레이어 시트(몸·무기·갑옷 등)를 체크해 한 장으로 겹친다(레이어별 색조 지정 가능). 이름 예 `knight@sword-plate` — 키 이름에는 `@` 를 쓸 수 있다.
- **시트 설정 프리셋**: 격자·배경 제거·후처리·변종 설정을 이름 붙여 저장했다가 다른 시트에 적용.

## 적용 예
```js
portraits: { warrior: 'assets/portraits/warrior.png', '레온': 'assets/portraits/leon.png' },
sprites:   { slime: 'assets/sprites/slime.png' },
```

### 장비 외형(시트 이름 규칙)
- 시트 이름 `직업@무기-갑옷` (예 `knight@sword-plate`). 무기: `sword great spear bow staff mace dagger fist cook`, 갑옷: `cloth leather mail plate mythic`.
- 조회 순서: 이름 → 직업 → 기본 직업 각각에서 `@무기-갑옷` → `@무기` → `@갑옷` → 기본(`knight`). `mythic` 은 없으면 `plate`. 없는 조합은 자동으로 다음 후보로 대체되므로 일부만 만들어도 된다.

- 매니페스트 `cell`(시트 칸 크기, 기본 128): 64px 시트는 `cell: 64` 로 두면 게임이 도트 그대로 `size` 크기로 확대해 그린다. 변환 도구의 `확대` 옵션으로 미리 2배로 키워 128 규격에 맞출 수도 있다(픽셀 그대로 / Scale2x).
